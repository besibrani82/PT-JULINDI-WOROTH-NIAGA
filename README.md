# PT JULINDI WOROTH NIAGA

Website resmi untuk PT JULINDI WOROTH NIAGA — perusahaan ekspor buah pinang berkualitas dari Jambi, Indonesia.

## 🌐 Tentang Kami
PT JULINDI WOROTH NIAGA adalah perusahaan yang bergerak di bidang ekspor buah pinang, khususnya jenis **Goli** dan **Kering**, ke berbagai negara. Kami mengutamakan kualitas produk, ketepatan pengiriman, dan pelayanan terbaik.

## 🚀 Fitur Website
- Halaman Beranda
- Tentang Perusahaan
- Produk (Pinang Goli & Kering)
- Layanan Kami
- Kontak & Informasi

## 🛠️ Teknologi
- React + Vite
- Tailwind CSS
- React Router DOM

## 📦 Cara Jalankan di Lokal
```bash
npm install
npm run dev
```

## ☁️ Deploy ke Vercel
1. Push proyek ke GitHub
2. Login ke [https://vercel.com](https://vercel.com)
3. Klik "Add New Project"
4. Pilih repo ini
5. Framework: Vite
6. Deploy!
